# По следу
Интерактивный учебник правил ездового спорта на русском языке. Первая версия: иллюстрированная трасса от первого лица, 4 учебных ситуации, объяснения ответов, сохранение прогресса в localStorage, поиск по полному документу и скачивание оригинала.

## Запуск
Нужен Node.js 24. Внешние зависимости и ключи не требуются.

```sh
cd /workspace/Pravila
npm run dev
```
Сервер слушает 0.0.0.0:3000. Для другого порта: `PORT=3001 npm run dev`.

Источник: предоставленный пользователем документ «ПРАВИЛА ЕЗДОВОЙ СПОРТ 2022.docx», приказ №1103 с изменениями №1209 от 14.12.2022. Учебные объяснения — адаптация, полный текст доступен в разделе правил. Актуальность редакции на дату соревнований не установлена.

Трасса — схематичная SVG-иллюстрация, а не физический симулятор. Прогресс хранится только в текущем браузере. Для шрифта используется Google Fonts с системным запасным шрифтом.

## Просмотр сайта через GitHub Pages
В репозитории откройте Settings → Pages. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку / (root), затем Save. После завершения публикации нажмите Visit site. Адрес сайта: https://lenka-lamazi.github.io/Pravila/ (работает только после включения Pages).
